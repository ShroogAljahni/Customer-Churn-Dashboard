# 📊 Customer Churn & Risk Analysis Dashboard (Power BI)

## 📝 Description
تطبيق عملي ضمن دورة Power BI لتحليل معدلات تسرب العملاء (Customer Churn) وتقييم المخاطر، بهدف تقديم رؤى تفاعلية تساعد على تحسين استراتيجيات الاحتفاظ بالعملاء.

## 🔑 Key Features & Insights
* **Churn Analysis:** تحليل نسبة التسرب (26.54%) وتوزعها حسب نوع اشتراك الإنترنت ووسيلة الدفع.
* **Customer Risk:** تحديد العملاء المعرضين للمخاطر وتتبع التذاكر الفنية والأدبية (Tech & Admin Tickets).
* **Demographics & Contracts:** تحليل التسرب بناءً على نوع العقد، مدة الاشتراك، والخصائص الديموغرافية.

## 🛠️ Tools Used
* Power BI Desktop
* DAX Measures (Total Customers, Churn Rate, Yearly Charges, etc.)
* Power Query (Data Cleaning & Transformation)
